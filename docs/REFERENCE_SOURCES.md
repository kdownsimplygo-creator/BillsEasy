## 2. IP Protection, Clean-Room Policy & Safety Safeguards

1. **No Code Copying:** Under no circumstances shall binary reverse engineering, decompilation, or direct copying of proprietary source code or assets be performed.
2. **Domain Model Extraction Only:** References are consulted strictly to understand standard business logic, statutory compliance equations, and operator mental models.
3. **No Commercial Licensing Violations:** No pirated software, key generators, or bypassed trial versions are downloaded or executed.
4. **Independent Implementation:** All database schemas, software architectures, UI components, and codebases in BillsEasy are built from first principles in modern C# and WPF.
